**Stage:** Post-v1 maintenance. Moved to git, split into modules, automated

## What got built

The single 2,560-line `index.html` became a repo: markup in `index.html`,
styles in four `css/` files, and one ES module per feature in `js/`, with
`js/main.js` owning startup order. A permanent test suite (56 tests: 38
browser scenarios with a fake Firebase and a controlled clock, 18 unit tests
on `js/lib/`) replaces the throwaway harnesses of earlier sessions. The
end-of-session tab title now blinks until the person is back.

## Decisions made

- **ES modules** over one file or plain scripts (Santi's call, on
  recommendation). Cost: no more double-click opening; always the Pages URL.
- **The timer emits events and features listen**, instead of calling into
  them. Retires the declaration-order hazard behind the 09-10 crash.
- **Session writes wait for the category vocabulary** (5s backstop), a
  generalisation of what only crash recovery did before.
- **Title blinks every second, no time limit** (Santi's call). Stops on
  returning to the tab/window, any click or key, or Start/Reset. Beat comes
  from a Web Worker, since a hidden tab's own timers slow to once a minute.
- **Roadmap and session logs live in the repo** (`docs/`) (Santi's call).
- **Git history replaces the `index-pre-*-backup.html` files.**
- **Interim security rules** (`database.rules.json`, sign-in required) to
  publish now, since the repo is public; per-UID rules wait on Kristina.
