# Session — 2026-11-17

**Stage** Unified category breakdown.

## What got built

The dashboard ranks Progress columns and standalone categories from the same
session log. The five largest categories appear first, with an expandable
remainder included in the total and the bar. Opening a column shows task
subtotals and any time logged directly to the column. The partner’s lifetime
total is now in Activity.

The timer shows the task’s column beneath its name. A shared label can be set
explicitly for a Progress selection. Time management shows and filters
sessions using the same category assignment as Dashboard.

## Decisions made

Use the column recorded on the session so moved tasks leave their earlier
time in the original column. Keep standalone labels and columns keyed
separately, including when they have the same display name. Existing
session records and private Progress links supply the report.
