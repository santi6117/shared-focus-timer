# Session — 2026-10-09

**Stage:** Swirl performance improvement, reviewed locally by Santi and
approved for publication.

## What got built

Swirl's moving colours render on one bounded canvas instead of eight large
CSS layers. The same palette, orbit speeds, wobble and paper/grain textures
remain. A local preview uses fake sample data, without touching the live
database. Santi called it "basically identical and much less lag" in Zen.

## Decisions made

- Cap the canvas's longest edge at 960 pixels, independently of Retina
  scaling, and draw at up to 30fps. Soft gradients tolerate this smaller
  surface; the crisp paper and grain stay at full display resolution.
- Cache eight small gradient images. Read palette, sizes and timing from
  CSS on resize rather than computing styles every frame.
- Stop drawing when hidden, unselected or reduced-motion is requested.
  Preserve the CSS version when a 2D canvas context is unavailable.
- Keep timer tests in reduced motion, with dedicated short motion tests.
  Long stopwatch tests jump the clock while short tests cover normal ticks.
- Show the local preview before pushing; Santi reviewed it and authorized
  publication.

## State of the code

Visual comparisons in Chromium and Firefox at Retina scaling showed the
same appearance without page errors. Added tests for sizing and motion,
resize, visibility, wallpaper switching, reduced motion and the CSS fallback.
All 112 tests pass, including the new wallpaper checks. Santi approved the
reviewed implementation for the live site.
Headless performance measurements were variable; no CPU saving percentage
is claimed. Santi's own browser preview confirmed the improvement.
