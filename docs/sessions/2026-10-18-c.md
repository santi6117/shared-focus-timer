## What got built

The calendar validates saved backfill timezones before using them to replace
the browser default or lock the input. Missing, empty, whitespace-only, and
invalid values leave the field editable. Preview and publication allow an
explicitly reviewed replacement for malformed metadata, while valid saved
timezones retain their attribution lock. User input is trimmed before preview.

## Decisions made

Recovery still requires an unchanged preview and explicit publication; it does
not silently choose a historical timezone or publish old sessions. The browser
timezone is the starting suggestion, and Puerto Rico history can be attributed
to `America/Puerto_Rico`. No new layout or timezone picker was introduced.
